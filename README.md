# Sistema de Barbearia V1.0

Sistema de gerenciamento de agendamentos para barbearia, desenvolvido em Python.

## Funcionalidades

- Cadastro de clientes.
- Cadastro de agendamentos.
- Listagem de agendamentos.
- Cancelamento de agendamentos.
- Reagendamento.
- Validação de datas e horários.
- Verificação de disponibilidade para evitar conflitos de horários.
- Cadastro de serviços disponíveis.

## Tecnologias utilizadas

- Python 3
- Biblioteca `datetime`

## Como executar

1. Tenha o Python 3 instalado.
2. Baixe ou clone este repositório.
3. Abra a pasta do projeto no terminal.
4. Execute:

```bash
python barbearia_v1.py
```

## Limitações da versão 1.0

- Os dados são armazenados em memória e são perdidos ao encerrar o programa.
- O sistema funciona pelo terminal.
- O sistema possui um único barbeiro cadastrado.
